# FoodExpress

A modern frontend-only food ordering website built with React, Vite, React Router, Lucide icons, and localStorage.

## Features

- Responsive premium food delivery UI
- Food catalog with category and spice filtering
- Favorites and cart persisted with localStorage
- Food detail page with dynamic spice and portion selection
- Order and profile pages
- Fully frontend-only, no backend or API required

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite in the browser.
